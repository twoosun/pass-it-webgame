# PASS IT! — 1차 웹 프로토타입

폭탄을 가진 플레이어가 제한시간 안에 다른 플레이어와 접촉해 폭탄을 넘기는 2~4인 실시간 웹게임입니다. 서버 권한형 이동/충돌 판정, 5개 라운드, 방 코드 로비를 포함합니다.

## 실행

Node.js 20 이상에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 한 PC에서 테스트하려면 브라우저 창이나 시크릿 창을 2개 열고, 첫 창에서 방을 만든 뒤 두 번째 창에서 5자리 코드를 입력하세요. 같은 Wi-Fi의 다른 기기는 방화벽에서 Node.js를 허용한 뒤 `http://<호스트-PC의-IP>:3000`으로 접속할 수 있습니다.

## 조작

- 이동: `WASD` 또는 방향키
- 점프: `Space`
- 대시: `Shift` (1.8초 재사용 대기)
- 폭탄 던지기: `E` (라운드당 2회)
- 패리: `Q` (날아오는 폭탄 반사 및 접촉 전달 방어, 3초 재사용 대기)
- 폭탄 전달: 다른 플레이어와 접촉 (받은 뒤 2초간 재전달 불가)

공중에서는 위 방향 입력으로 상승 시간이 늘어나고 아래 방향 입력으로 더 빠르게 낙하합니다. 발판 밖 허공으로 떨어지면 시작 지점으로 복귀합니다. 방 생성 시 선택적으로 비밀번호를 지정할 수 있으며, 첫 화면의 방 목록에서 현재 대기 중인 방과 잠금 여부를 확인할 수 있습니다.

## 전체 개발 계획

1. **1차 프로토타입(현재)**: 방 생성/입장, 서버 동기화, 이동·점프·대시, 폭탄 전달, 4종 장애물, 5라운드와 점수 UI.
2. **게임 감각 개선**: 지연 보정과 클라이언트 예측, 충돌/카메라/이펙트 개선, 맵 2~3종과 랜덤 스폰.
3. **서비스 안정화**: 재접속, 방장 위임 보강, AFK/비정상 입력 방어, 모바일 UX, 부하 테스트.
4. **배포**: HTTPS/WSS 호스팅, 간단한 닉네임 필터, 분석/오류 수집, 초대 링크.

## 기술 구성

- Node.js 정적 HTTP 서버 + `ws` WebSocket
- HTML5 Canvas + 순수 JavaScript 클라이언트
- 빌드 단계나 데이터베이스 없이 바로 실행 가능한 구조

게임 상태와 폭탄 충돌은 서버가 판정합니다. 현재 버전은 빠른 플레이테스트용으로, 영구 계정·매치메이킹·재접속은 범위에서 제외했습니다.
